# NoShowGuard — Общий план проекта (Project Overview)

> **Суть продукта:** Легковесный Telegram-бот + Telegram Mini App (TMA) для частных мастеров сферы услуг (бьюти, массаж, тренеры, коучи), который ликвидирует проблему неявок клиентов ("no-show") за счет автоматического сбора гарантийного депозита 300–500 ₽ по СБП.

---

## 🎯 Проблема и решение

| Было (Боль мастера) | Стало с NoShowGuard |
|---|---|
| 15–25% клиентов не приходят на сеанс без предупреждения | **0% потерь:** неявка компенсируется удержанием 300–500 ₽ депозита |
| Потеря 5 000 – 20 000 ₽ в месяц из-за пустых окон | Освободившийся слот за 1 минуту предлагается листу ожидания со скидкой |
| YCLIENTS стоит от 19 000 ₽/год, сложен, перегружен складами | **490 ₽/мес**, настройка за 3 минуты, работает прямо внутри Telegram |
| Ручные неловкие просьбы «скиньте предоплату на Сбер» | Нативная оплата в 2 клика через СБП без передачи номеров карт |

---

## 🔄 Петля ценности (Core Loop)

```
[Мастер]                                    [Клиент]
   │                                           │
   ├─► Ссылка в шапке профиля / канале ───────►│ Открывает Mini App в Telegram
   │                                           ├─► Выбирает дату и свободное время
   │                                           ├─► Вносит депозит 300 ₽ по СБП (в 1 клик)
   │◄── Мгновенное пуш-уведомление о брони ────┤
   │                                           │
   ▼                                           ▼
[За 24 и 2 часа до сеанса] ───────────────► Получает авто-напоминание в Telegram
   │                                           │
   ├─► Если клиент пришел: депозит идет в счет оплаты сеанса (остаток на месте)
   └─► Если клиент не пришел: депозит компенсирует простой мастера
```

## 🧱 Архитектурный стек в 1 строку

- **Frontend:** React 19 + TypeScript + Vite + `@telegram-apps/sdk-react` + Tailwind CSS / shadcn.
- **Backend:** Python 3.12 + FastAPI + `aiogram 3.x` (единый асинхронный сервис).
- **База данных:** SQLite в режиме WAL (для старта на VPS) → PostgreSQL при масштабировании.
- **Платежи:** ЮKassa СБП API (динамические deep-link ссылки на банки РФ, комиссия 0.4–0.7%).
- **Фоновые задачи:** `APScheduler` (cron-напоминания без Redis/Celery на старте).

---

## ⚖️ Юридическая основа
- Платеж оформляется как **«Обеспечительный платеж за резервирование временного слота»** (ст. 381.1 ГК РФ), покрывающий фактически понесенные расходы (ФПР, ст. 32 ЗоЗПП, ст. 782 ГК РФ).
- При явке сумма на 100% засчитывается в стоимость основной услуги мастера.
- Мастера-самозанятые освобождены от онлайн-касс (54-ФЗ).

## 🏁 Критерии готовности MVP
- [ ] Мастер может за 1 минуту создать свой график работы через Telegram-бота.
- [ ] Клиент по ссылке открывает Mini App, видит только свободные слоты и оплачивает 300 ₽ через СБП.
- [ ] При оплате слот блокируется, мастер получает уведомление.
- [ ] За 24 и 2 часа клиенту автоматически приходит напоминание с кнопкой отмены.
- [ ] При отмене слот моментально предлагается листу ожидания со скидкой 10%.
